# Spotify_Analysis_Dashboard
🎵 **Spotify Music Listening Behaviour Analysis Dashboard | Power BI Project**

Excited to share my latest Data Analytics project – an interactive Spotify Music Analysis Dashboard built using Power BI!

Through this dashboard, I explored music listening patterns and transformed raw listening data into meaningful visual insights.

📊 **Key Insights & Features:**
🔹 Album, Artist & Track Listening Trends  
🔹 Year-over-Year Performance Comparison  
🔹 Weekly vs Weekend Listening Behaviour  
🔹 Top 5 Most Played Albums & Artists  
🔹 Most Played Tracks Analysis  
🔹 Interactive Filters for Platform, Shuffled & Skipped Tracks  

🛠️ **Tools Used:** Power BI, DAX, Data Cleaning & Data Visualization.

This project helped me strengthen my practical skills in data analysis, dashboard development, and presenting insights through visual storytelling.
